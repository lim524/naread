# MVP 검증 결과

검증일: 2026-11-10 (한국 시간)

사용자 흐름: 홈에서 분석을 선택하고 입력 정보를 서버로 전달하며, Supabase에 본인 결과를 저장하고 회원 종합 프로필로 Gemini 운세를 생성하여 당일 재사용하는 서비스.

| 경계                        | 결과                                   | 근거                                                             |
| --------------------------- | -------------------------------------- | ---------------------------------------------------------------- |
| PC·모바일 화면              | 통과                                   | Chromium 데스크톱 및 iPhone 13 크기의 공개 화면·입력·메뉴 테스트 |
| 브라우저 → 분석 API         | 통과                                   | 3단계 입력 완료 후 실제 POST, 연결 설정 안내가 UI에 표시됨       |
| API → 실제 외부 서비스      | 미검증                                 | Supabase·Gemini 환경변수가 제공되지 않음                         |
| PostgreSQL 업무 규칙        | 통과                                   | 실제 migration을 PGlite에서 실행한 10개 DB 테스트                |
| 입력·사주·날짜·응답 형식    | 통과                                   | core 테스트 5개                                                  |
| 결과 → 화면                 | 공개 샘플 통과 / 실제 개인 결과 미검증 | 실제 AI 호출이 없어 개인 결과를 생성했다고 주장하지 않음         |
| SEO·관리자 보호·광고 비활성 | 통과                                   | noindex, 사이트맵, ads.txt, 관리자 API 403 확인                  |
| 빌드·타입                   | 통과                                   | `npm run build`, `npm run typecheck`                             |

DB 테스트는 RLS, 함수 실행 권한, 하루 5회, 실패 복구, 당일 운세 재사용, 다음 날 생성, 중복 예약 차단, 예산 상한, 만료 복구, 익명 이전, 계정 연쇄 삭제, 종합 결과 삭제를 포함합니다. 실제 JWT 공급자와 OAuth/SMTP를 테스트하는 환경은 아닙니다.

브라우저 테스트 10개는 PC 5개, 모바일 5개입니다. 기본 환경변수가 없는 개발 상태를 기준으로 연결 오류를 검증합니다. 실 서비스 환경변수를 설정하면 해당 테스트의 오류 예상은 실제 성공 흐름 테스트로 변경해야 합니다.

운영 전: 두 개의 실제 계정으로 Google·이메일 인증, 비회원 결과 이전, Gemini 결과 생성/재조회, 계정 간 접근 차단, 운세 당일 재사용, 삭제/탈퇴를 검증해야 합니다. 비용과 데이터 처리 계약도 운영 설정과 함께 확인하세요.
