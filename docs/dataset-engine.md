# 데이터셋 분석 엔진 · 2026.11.10-v1

이용 정책은 [일일 포인트제](points.md)로 변경했습니다. 아래의 이전 5회 정책은 003 이전 구현 설명이며, 운영 시 001·002·003 마이그레이션을 모두 적용합니다.

## 동작과 구성

- `/api/analyze/individual`: 사주·MBTI·태몽을 파일 데이터셋으로 해석하며 AI 모듈을 가져오지 않는다.
- `/api/analyze`: 알려진 정보 두 가지 이상은 Gemini 종합 연결, 한 가지는 AI 없는 부분 결과, 전부 모름은 입력 오류로 처리한다.
- 등록된 상징을 하나도 확인하지 못한 태몽은 종합 AI의 근거 수에 포함하지 않고 미등록 안내와 부분 결과를 유지한다.
- `/sample`: 설명용 생년월일로 계산한 원국·오행 카드와 MBTI 네 글자별 해설, 사주와 함께 읽는 예시를 볼 수 있다. 개인 분석과 구분하는 샘플 안내를 유지한다.
- AI 입력에서 원본 생년월일·출생 시각·별칭은 제외한다. 계산한 원국, 개별 해석, 꿈의 단서, 누락 항목, 데이터 버전과 선택 자기소개만 전달한다.
- 같은 소유자의 동일 입력·데이터 버전 종합 결과는 24시간 재사용한다. 기존 AI 예산·동시 요청·실패 복구를 유지한다.
- 오늘의 조언은 기본적으로 날짜별 자체 데이터셋이다. `AI_FORTUNE_ENABLED=true`일 때만 기존 Gemini 운세 경로를 사용한다.

| 데이터 | 초기 구현 |
| --- | --- |
| 사주 | 10천간·12지지·오행 5종·십성 10종·합/충/형/파/해, 10개 결과 섹션 |
| MBTI | 16유형별 독립 본문 16항목과 생활 예시 4개, 유형당 3,100~3,400자, 8개 선호 설명 |
| 간이 성향 | 자체 작성 12문항. 공식 검사가 아닌 참고 유형이며 사용자가 적용 여부를 선택 |
| 태몽 | 핵심 상징 38종, 행동 15종, 속성·분위기 11종, 조합 규칙 5종 |
| 이미지 | 기존 100종 + 신규 37종(기둥 4·오행 5·MBTI 8·꿈 소재 18·조합 2) |

계산과 콘텐츠를 분리하고 출처·버전·수정일·검토 상태를 기록한다. 전통 개념과 직접 작성한 현대적인 성찰 예시를 구분한다. 결과에는 상세 본문·근거·개념 설명의 스냅샷을 저장해 이후 콘텐츠 수정으로 기존 결과가 다시 생성되지 않게 한다.

MBTI–사주 연결은 일간의 상징과 사용자가 알려준 네 선호를 나란히 읽는 예시다. 상관관계·인과관계·궁합 점수로 주장하지 않고 오행 개수로 유형을 추론하지 않는다.

## 역법 조건

고정 한국 표준시 UTC+9의 입력 시계 시각을 사용한다. 라이브러리의 UTC+8 절기 시각은 같은 순간의 한국 시간과 비교한다. 일주·시주는 한국 시계 날짜를 유지하고 연월주의 십성도 한국 날짜의 일간을 기준으로 관계를 계산한다. 연주는 입춘, 월주는 절입, 일주는 `sect=2`의 자정 경계, 시주는 라이브러리의 자시 구간 규칙을 따른다.

출생지 경도·진태양시·과거 표준시 변경·서머타임은 보정하지 않는다. 음력은 lunar-typescript의 중국 역법이며 한국 공식 음력과 다를 수 있다. 실제 윤달 존재 여부와 날짜는 검증하지만 한국 공식 역법 완전 지원으로 표시하지 않는다.

시간 미상은 정오를 연월주 계산의 기준으로 삼고 시주·시간 오행·시주 관계를 제외한다. 절입 당일에는 연월주·계절·관련 집계가 참고값이며 확정할 수 없음을 결과에 표시한다. 오행은 겉의 천간·지지 각각을 한 번 세며 지장간은 별도 표기한다. 단순 개수로 세력·용신을 판정하지 않는다. 대운·세운·용신 판정은 구현하지 않았다.

## 태몽과 이미지

NFC/공백 정규화, 긴 동의어 우선 사전 매칭, 조사와 문장 패턴을 사용한다. 범용 형태소·의미 분석기는 아니므로 긴 복합절·대명사·생략된 주체를 정확히 복원한다고 주장하지 않는다. 모호한 내용은 확인 필요로 남기고, 미등록 소재는 새 해몽을 만들지 않는다.

확인 화면에서 상징을 선택·제외하고 속성의 대상을 수정하거나 제외할 수 있다. 행동의 주체·대상·부정도 수정한다. 조합은 주체와 대상의 방향이 실제 규칙에 맞을 때만 적용한다. 부분적으로 인식한 내용만으로도 분석이 끝까지 진행된다.

이미지는 실제 카탈로그 파일만 참조한다. 조합(현재 여의주를 문 용·집으로 들어가는 호랑이), 색상에 맞는 소재, 소재 기본, 범주별 기본 순으로 매칭한다. 명시된 색과 다른 조합 그림은 사용하지 않는다. 전용 그림이 없는 복잡한 조합도 임의의 파일명을 만들지 않는다.

## 저장과 운영 설정

기존 Supabase 프로젝트에는 다음 추가 마이그레이션을 적용한다.

```text
supabase/migrations/002_dataset_readings.sql
```

새 프로젝트는 `001_nailgi.sql` 다음에 `002_dataset_readings.sql`을 적용한다. 추가 함수는 서비스 역할 전용이며 기존 소유권·RLS·게스트 이전·삭제 구조를 유지한다. 데이터셋 분석도 기존 하루 5회 이용량에 포함하지만 AI 비용이나 사용 로그는 만들지 않는다. 날짜별 조언은 캐시하며 분석 횟수를 차감하지 않는다.

Supabase 연결이 없는 로컬 환경의 개별 결과는 현재 탭의 `sessionStorage`에만 보관한다. 실제 계산·해석 결과이며 새로고침과 탭 내 삭제를 지원한다. 탭을 닫으면 사라지고 계정으로 자동 이전되지 않는다고 명시한다. AI 종합 생성과 서버 기록은 Supabase·Gemini 설정이 필요하다.

PNG 카드는 1200×1600으로 저장한다. 파일 공유를 지원하지 않는 브라우저는 다운로드로 전환하며 개인 결과 URL을 공개 공유하지 않는다.

## 자산과 검증

- `public/illustrations/concepts-v1/`: 원본 PNG, 768px WebP, 카탈로그·미리보기
- `docs/concept-illustration-prompts.json`: 내장 image_gen 생성 프롬프트
- `output/illustration-review/`: 부적합 시안. 제품에서 참조하지 않음
- 재변환: `node scripts/build-concept-assets.cjs`
- 검사: `npm test`, `npm run typecheck`, `npm run build`, `npx playwright test`

모든 콘텐츠는 `editorial-draft`다. 전문가 검토, 한국 공식 음력 대조표 전체 검증, 범용 한국어 관계 추출, 300~500개 상징 확장은 완료하지 않았다. 해당 범위를 완료한 것처럼 표시하지 않고 결과에 검토 상태·계산 조건·불확실성을 노출한다. 민속 기록을 성별·건강·재능·재산·미래를 판정하는 근거로 사용하지 않는다.
