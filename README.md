# 나읽기

사주·MBTI·태몽 개별 분석과 종합 해석을 무료로 제공합니다. 로그인, 외부 AI, 포인트, 서비스 DB 없이 동작하며 광고를 통한 운영을 계획합니다.

## 로컬 실행

Node.js 22 이상에서 `npm install`, `npm run dev`를 실행하고 http://localhost:3000 에 접속하세요. 분석에 API 키는 필요 없습니다. 공개 사이트 주소 등은 `.env.example`을 참고해 `.env.local`에 설정합니다.

## 분석과 보관

사주 원국은 달력 라이브러리로 계산합니다. 종합 분석은 사주 기질·MBTI 선호·확인된 태몽의 조건별 문단을 연결해 제공합니다. 결과와 입력은 이 브라우저의 IndexedDB에 보관하며 서버 DB에 저장하지 않습니다. 내 결과(`/results`)에서 재열람·삭제·JSON 백업 및 복원이 가능합니다. 복원할 때 입력을 검증하고 현재 해석 기준으로 재구성합니다. 브라우저 데이터를 지우면 사라질 수 있으며 다른 기기로 자동 동기화되지 않습니다. 이전 sessionStorage 결과는 해당 결과 주소를 방문할 때 IndexedDB로 이전됩니다.

종합 결과를 만들면 홈의 샘플 카드가 개인 프로필로 바뀝니다. 소재와 색상이 매칭된 기존 삽화를 사용하며 이미지를 새로 생성하지 않습니다. 최근 개별 결과가 프로필의 정보와 다르면 다시 종합할 수 있고, 새 분석의 입력은 저장한 최근 정보를 바탕으로 미리 채웁니다.

## 태몽 해석

결과 화면은 ‘나의 이야기 → 20개 주제별 본문 → 개념 설명’ 순서입니다. 사주·MBTI·종합 결과는 성향별 핵심 문장, 생활 속 상황, 입력에 따른 세부 해석, 장점이 마찰로 바뀌는 지점을 연결합니다. 태몽 단독은 실제 성격을 추정하지 않고 주인공·색·거리·접촉·교류·감정 등 20개 장면 관점으로 읽습니다. 내용의 버전은 `storyVersion`으로 구분하며 이전 결과를 다시 열 때 기존 분석 데이터는 유지하고 이야기 본문을 갱신합니다. 선택한 내 프로필은 이 과정에서 바뀌지 않습니다.

태몽은 18개 카테고리의 98개 소재와 583개 고유 이름·동의어를 지원합니다. 소재별 설명, 범주별 비교, 색·크기·수량·분위기, 행동의 방향, 명확한 소재 조합을 나누어 해석합니다. 연꽃과 장미 같은 세부 소재를 일반 꽃과 중복 계산하지 않으며, 부정된 등장과 행동은 완료된 장면으로 해석하지 않습니다. 자동 인식은 규칙 기반이므로 생략된 주체나 다의어는 확정하지 않으며 확인 화면에서 카테고리·동의어 검색과 관계 수정을 할 수 있습니다.

## 기간별 운세

저장된 종합 프로필이 있어야 `/fortune`을 이용할 수 있습니다. 일간·주간·월간·연간의 기간은 한국 시간, 월요일 시작 주, 달력상의 월·년을 기준으로 합니다. 일간은 당일, 주간은 월요일의 일진, 월간은 15일 정오의 월주, 연간은 7월 1일의 입춘 기준 연주를 대표 간지로 사용합니다. 이 대표 간지와 일간의 오행 관계에 따라 준비된 주제를 선택하고, 기간별 관점·일간별 기질·MBTI 선호 문단을 함께 읽습니다. 기간 중 절입으로 바뀌는 모든 간지와 대운·신강약·용신을 종합 계산하는 체계는 아닙니다. 태몽은 프로필의 상징에 사용하며 일별 사건의 판단 근거로 쓰지 않습니다.

같은 프로필 ID·해석 버전·기간·시작일의 운세는 IndexedDB에 캐시됩니다. 종합 결과를 삭제하면 연결된 운세도 삭제하며, 다른 저장된 종합 결과는 내 프로필로 다시 지정할 수 있습니다. 브라우저 안에서 작동하는 이용 조건이며 계정 인증 방식의 접근 제어는 아닙니다.

## 애드센스

결과와 운세 화면에 광고 슬롯이 있습니다. 기본값은 비활성입니다. 승인된 게시자 ID와 슬롯을 `NEXT_PUBLIC_ADSENSE_CLIENT`, `NEXT_PUBLIC_ADSENSE_SLOT`에 넣고, 동의 관리 주소 `CMP_SCRIPT_URL` 및 `CMP_READY=true`, `ADS_ENABLED=true`를 설정하면 표시됩니다. Google 소유권 확인은 `GOOGLE_SITE_VERIFICATION`으로 설정하며 `/ads.txt`는 게시자 설정을 반영합니다. 실제 광고 활성화와 배포는 별도로 진행합니다.

## 검증

웹에서 사용하는 이미지는 WebP, 공유 미리보기는 JPEG로 제공합니다. PNG 원본과 검토용 시트는 로컬 `output/image-originals` 및 `output/illustration-review`에 보관하며 Git과 배포 대상에서 제외합니다. `npm run images:optimize`는 로컬 원본이 있는 대형 삽화를 해상도 유지·WebP 품질 80으로 최적화합니다. 원본이 없는 체크아웃에서는 이미 제공된 WebP를 그대로 사용합니다. 원본은 저장소에 포함되지 않으므로 새 기기에서 원본 작업을 하려면 별도로 옮겨야 합니다.

`npm run typecheck`, `npm test`, `npm run build`. 브라우저 테스트는 빌드 후 `npx playwright test`로 실행합니다.

`supabase/`의 이전 마이그레이션 및 기존 운영 관련 문서는 과거 구현 기록이며 현재 서비스에서는 사용하지 않습니다. 기존 외부 DB에 저장된 데이터는 이 코드 변경으로 삭제되지 않습니다.
